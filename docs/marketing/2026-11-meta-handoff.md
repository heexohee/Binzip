## 집행 전 모스트 확인 요청
1. 광고 계정·인스타 페이지 소유자, 일 예산·총예산·기간, 매체비 별도 결제 여부.
2. 두 목적을 광고 세트/소재/랜딩별로 분리하고, 홈 대신 해당 안내 페이지로 연결.
3. Meta Pixel/데이터셋 설치와 Lead 전환 검증 담당자를 확정. 현재 사이트에는 Meta Pixel이 없으므로 GA4의 generate_lead를 Meta 최적화 신호로 착각하지 말 것.
4. 픽셀 미준비 시 바로 웹 전환 최적화가 된다고 보고하지 말고, 트래픽 캠페인에서 실제 제공되는 랜딩페이지 조회 최적화 사용 가능 여부를 계정 UI에서 확인. 링크 클릭 수만 성과로 보고하지 말 것.
5. 주택 관련 광고 분류/특별 광고 카테고리 적용 여부는 실제 서비스와 소재를 기준으로 Meta 정책·계정 화면에서 확인.
6. 첫 집행 전 모바일 인스타 내부 브라우저에서 페이지 → 폼 → 접수 확인을 함께 검증.
