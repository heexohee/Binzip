# 대보리 단독주택 거래 근거

확인일: 2026-09-15. 국토교통부 공개시스템의 실제 웹 UI에서 수동 확인한 스냅샷.

- 원문: https://rt.molit.go.kr/pt/gis/gis.do?srhThingSecd=C&mobileAt=
- 조회: 단독/다가구 → 경상북도 → 포항시 남구 → 호미곶면 → 검색 → 매매 → 법정리 대보리 → 2026년 및 2025년.
- 각 연도 선택 직후의 이전 목록은 사용하지 않고 비동기 갱신 완료 뒤 법정리와 기준년도를 확인했다.
- 해제사유 발생일 모두 `-`. 계약 신고 자료이며 잔금 완료나 소유권 이전을 확인한 것은 아니다.

2025년 대보리에서 추가 확인한 2025-04-08 거래(1**, 해맞이로, 연면적24.99㎡, 대지61㎡, 4100만원, 직거래)는 연면적60~85㎡ 조건 밖이므로 비교표에서 제외했다. 2026년 대보리 선택 완료 후 목록에는 1월 거래 1건만 나타났다. 호미곶면 전체의 6·7·9월 거래는 다른 리이므로 사용하지 않았다.

세 거래는 같은 리·유사 연면적 조건의 참고자료다. 정확한 거리, 도로, 건축연도, 손상 상태, 거래당사자 관계 등은 검증하지 않았다. 연면적 비례 환산이나 수리비 단순 차감으로 이 집의 가치를 만들어내지 않는다. 종전 근거 없는 2000만원과 그에 종속된 중개보수12만원을 제거하고 실제 비교 거래 범위4830~9700만원을 표시했다. 이 범위는 예측구간이 아니다.

중개보수: https://www.gb.go.kr/Main/finace/page.do?mnu_uid=15502
경북도청 안내의 경상북도 주택의 중개보수 등에 관한 조례 제2조 근거 및 주택 매매표 확인: 5천만원 미만0.6%/25만원, 5천만원 이상2억원 미만0.5%/80만원. 서울시 링크 제거. 실제 거래가격 미정이므로 보수액을 확정하지 않는다.

데이터는 `src/pohang-market-evidence.ts`에 고정 저장하며 자동 갱신이나 실시간 API 연동을 뜻하지 않는다. `.env.local`에 DATA_GO_KR_KEY가 없어 API로 수집하지 않았으며 브라우저의 공개자료를 사용했다. 기존 합성 거래 fixture는 본 비교표에 사용하지 않는다.

## 본문 간소화

후속 요청에 따라 최저·최고 범위 대신 확인 거래 3건 중 대상 주택66㎡와 연면적 차이가 가장 작은 67㎡ 거래(8000만원)를 본문 참고값으로 표시한다. 선정 기준은 가격이 아니라 연면적 차이이며, 이 집의 예상가로 바꾸지 않는다. 전체 거래표·출처·조회 조건 및 중개보수 설명은 기본 접힘으로 옮겼다.
