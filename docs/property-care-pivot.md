# 빈집 상태관리 앱 시제품

- 경로: `/care`
- 브랜치: `codex/property-care-app`
- 기존 진단·신청·메인 페이지 보존. 고객/현장 담당자 전환은 시연용이며 인증이 아니다.
- 최초 진단을 초기 상태 기록으로 두고, 정기 방문 보고와 추가 작업 결정을 같은 집에 연결한다.

## 시연 순서
1. 고객 홈에서 예정 방문과 담당자를 확인한다.
2. 현장 담당자로 전환 → 방문 시작 → 5개 점검 결과 → 사진·메모 → 보고 등록.
3. 고객으로 전환 → 방문 보고 열기 → 확인 완료.
4. 현장 담당자가 추가 작업명·이유·금액을 입력한다.
5. 고객이 승인/보류한다. 승인된 작업만 현장 담당자가 완료 처리할 수 있다.
6. 문의에서 양쪽 역할로 메시지를 남긴다.
7. 최초 진단에서 첫 상태 기록 및 기존 진단서 예시로 이동한다.

## 구현 경계
현재 페이지 메모리만 사용. 새로고침 시 초기화. 사진은 JPG/PNG/WebP, 장당 5MB 이하, 최대4장. 사진 없는 경우 이유 입력 필요. 실제 로그인·결제·서버 저장·외부 알림·AI 호출·음성 녹음은 연결하지 않음. 실제 주소에 연결된 주택/방문/담당자 정보는 가상 시연 자료다.

## 검증 (2026-09-14)
Next.js production build 통과. Chrome Playwright에서 미완료 체크리스트 제출 차단, 사진 업로드 및 고객 열람, 보고 확인, 추가 작업 승인/완료, 역할 간 메시지, 새로고침 초기화 확인. 375/390/768/1440px에서 고객 4개 탭 가로 넘침 없음. 실제 휴대폰 검증은 하지 않았음.
