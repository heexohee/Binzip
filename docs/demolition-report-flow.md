# 철거 준비부터 진행 확인까지 — 예시 진단서 리뉴얼

작성일: 2026-09-12

## 목적과 화면

사용자가 승인한 흐름은 **집의 정보 → 철거 준비사항 → 상담 맡기기 → 진행 상황 확인**이다. 진단서를 원스톱 철거 지원의 시작점으로 구성한다. 기존 브랜드·집토끼·20px 본문을 재사용하고, 상세 정보는 펼침으로 제공한다.

- `/example-report`와 `/example-report/easy`는 같은 `RenewedExampleReport`를 표시한다. 홈에서 들어오는 기본 예시도 새 구조를 사용한다.
- 실제 고객 `/report/[id]`와 신청 `/apply`의 데이터·조회·저장·발송 흐름은 변경하지 않는다.
- 지정 주소 대보리 126-6을 기준으로 만든 가상 사례다. 최상단에서 건물·거래·비용·진행 정보가 시연용이며 실제 상담·계약·공사는 진행되지 않음을 한 번 안내한다.

## 네 구간

1. 집의 정보: 건물 56.2㎡·대지 198㎡, 상속·단독 소유, 근저당 1건과 상환 예정액을 표시한다. 등기부·건축물대장, 주택 3건·토지 2건의 거래 사례, 매도 순회수액 계산기는 펼쳐 본다.
2. 철거 준비: 총 1,200만 원의 예산 내역과 담보·지원·현장 견적 준비를 보여준다. 서비스가 도울 일과 소유자가 준비할 일을 구분한다. 기존 공식 지원 자료와 연락처는 상세에서 유지한다.
3. 상담 맡기기: 지정 사례에 대한 상담 방식·시간·요청 내용을 입력한다. 브라우저 안에서 접수 화면으로 전환하고 진행 현황 제목으로 스크롤·포커스를 이동한다.
4. 진행 확인: 담당자, 주요 일정, 다음 안내, 소유자가 할 일, 자료 정리 현황을 보여준다. 별도의 ‘다른 단계 화면 보기’로 7개 상황을 둘러볼 수 있다.

매도·보유 가능성을 제거하거나 철거 필요성을 확정하지 않는다. 주변 거래와 매도 계산을 상세에 유지하며, 철거 관련 선행 확인사항을 상담의 입력으로 삼는다.

## 데이터와 금액

- 건물·등기 자료: `src/example-report-data.ts`
- 거래 사례·철거 예산·진행 단계: `src/example-demolition.ts`
- 주택 거래: 2,800 / 3,200 / 3,500만 원. 토지 거래: 3,900 / 4,400만 원. 실제 실거래 조회나 신고 내역을 사용하지 않았다.
- 철거 예산: 해체 450 + 짐·폐기물 330 + 설비·부지 정리 120 + 행정·현장 관리 100 + 예비비 150 + 진행지원 수수료 50 = 1,200만 원. 모두 시연용 값이다.
- 총액은 기존 계산기의 철거 정리비용과 일치한다. 진행지원 수수료 50만 원을 포함하며 별도로 중복 차감하지 않는다.
- 지원 선정·금액을 자동 확정하거나 가상 보조금을 만들어 총액에서 차감하지 않는다.

## 시연 범위

상담 요청과 화면 선택은 React 메모리에만 존재한다. DB·API 조회, 알림 발송, 실제 협력사 배정, 계약 체결·결제·공사 지시가 발생하지 않는다. 새로고침하면 상담 전으로 돌아간다. 입력값을 URL이나 저장소에 남기지 않는다.

상담 전에는 모든 단계가 대기다. 접수하면 첫 단계만 진행 중이며, 나머지는 예정이다. 단계 미리보기는 선택한 단계 이전만 완료 처리하고, 마무리 화면에서 7개 단계 모두 완료된다. 이는 실제 업무 진행을 바꾸는 기능이 아니다.

## 확인 항목

- 금액·상태 테스트: 예산과 계산기의 일치, 실제 고객 기본값 분리, 완료·진행·예정 상태 계산, 잘못된 단계 입력 처리.
- 브라우저: 두 경로, 모바일·PC 기본/상세 펼침, 상담 입력→접수→진행 화면, 모든 단계 전환, 재입력, 인쇄, 가로 넘침, 외부 제출 없음.
- 키보드: 표준 폼·라디오·select·details 사용, 포커스 표시, 접수 후 진행 제목 이동, 상태를 글로 표현.
