# 처분 순서 비교 (2026-09-13)

- 홈: 일반 매입 가상 사례의 아파트 세금 비교. 약 1억 413만원과 0원은 서로 다른 처분 순서의 조건부 계산이며 절세 실적이 아니다.
- /apply: 선택 입력. 취득 경위·날짜, 다른 주택, 매도 계획과 금액 및 계산 가정. 브라우저 메모리에서 /decision-report로 전달하며 새로고침하면 초기화한다.
- 신청 제출 시 검토용 입력 요약을 기존 condition 필드에 별도 단락으로 첨부한다. DB 마이그레이션 없이 운영자도 입력을 읽을 수 있다. 확인된 세무 판정으로 저장하지 않는다.
- /example-report 및 /example-report/easy: 기존 2018년 상속 사례에서 시작. 매입 사례는 버튼으로 전환하는 별도 시뮬레이션이다.
- 일반 진단서: 현재 탭 입력이 있으면 계산하고, 없으면 필요한 항목을 안내한다. 저장된 신청 정보의 자동 세무 판정은 제공하지 않는다.

## 계산 범위

2026년 매도, 단독명의 거주자, 기본세율/일반 장기보유공제 적용, 보유 2년 이상, 12억원 이하. 1세대1주택 요건 충족 및 동시 보유 특례 없음이라는 사용자 선택 가정 아래 비교한다. 증여·미등기·등록임대 등 별도 규정과 다른 과세대상 양도가 있는 경우는 범위 밖이다. 입력 누락/잘못된 날짜/고가주택/범위 밖 연도는 확인 필요로 처리한다. 취득순서만으로 상속특례를 확정하지 않는다.

비교는 아파트(다른 주택)의 양도소득세와 지방소득세만 대상으로 한다. 빈집 처분세금·거래비·정리비·대기비용과 최종 순회수액은 자동 산출하지 않는다. 세무사/중개사 자동매칭은 없으며 실제 운영자 신청 및 지원정보 페이지로 연결한다.
