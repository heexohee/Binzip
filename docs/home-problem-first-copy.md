# 메인 소개: 빈집 정리의 필요성에서 진단 신청으로

작성·근거 확인: 2026-09-12 · 로컬 메인 반영

## 구성

1. **시골 빈집, 그냥 두는 게 가장 쌀까요?** 소개·집토끼 아래에 무료 진단 주소 입력 폼을 통합한다. 주소·위성 지도 확인 → `/apply` 상세 내용·사진 접수로 이어진다.
2. 오래 비워둔 집에서 살펴야 할 세 가지: 안전·주변 환경 / 조치명령과 이행강제금 / 보유 중 세금.
3. **철거를 생각한다면, 비용과 순서부터 확인하세요.** 집의 기록, 철거 지원 조건·신청처, 견적 포함 범위와 절차를 정리하는 서비스임을 설명한다.
4. 진단서 예시 → 이용 순서 → FAQ → 마지막 신청 안내. 별도 지원·정보 안내 카드는 제거하고 하단의 ‘빈집 지원·정보 모음’ 링크를 유지한다.

첫 화면의 시작 버튼 자리에 주소 입력·확인 폼을 직접 배치하고, 별도 신청 영역과 ‘주소 확인 후, 아는 내용만 적어 주세요.’ 문구를 제거했다. 폼은 소개 문구·집토끼 아래에서 전체 너비를 사용한다. `#address-search`는 이 폼을 가리키며 마지막 신청 버튼과 다른 페이지의 주소 입력 링크도 동일한 위치로 이동한다. 기존 진단서·큰 글씨 시안, 집토끼 자산·크기, 주소 조회·입력 데이터 처리 방식은 유지한다. 기존 네 가지 질문 섹션을 세 가지 철거 준비 안내로 대체해 중복 설명을 줄였다.

## 문구와 근거의 범위

사용자 확정 첫 화면 문구:

> **시골 빈집, 그냥 두는 게 가장 쌀까요?**
>
> 당장은 지출이 적어 보여도, 시간이 지나며 관리와 정비 부담이 커질 수 있습니다.
>
> **빈집진단서로 내 집의 상태와 지원 조건을 확인하고, 정리에 필요한 비용과 다음 순서를 알아보세요.**
>
> **내 빈집 무료로 확인하기**

무료 확인 버튼은 기존 주소 조회를 실행한다. 주소와 지도 확인 후 상세 입력으로 이어지는 순서는 동일하며, 처리 중에는 ‘주소 확인 중…’으로 표시한다. 하단 신청 링크도 같은 문구를 사용하고 첫 화면의 주소 입력으로 이동한다. 모든 빈집에서 방치 비용이 가장 높다거나 실제 절감 효과가 검증됐다는 뜻으로 쓰지 않는다.

| 주제 | 화면에서 말하는 내용 | 근거와 한계 |
| --- | --- | --- |
| 안전·주변 환경 | 문제가 생긴 빈집에는 정비가 필요할 수 있음 | [농림축산식품부 안내, 2024.07.02](https://mafra.go.kr/bbs/home/792/570719/artclView.do). 안전사고·위생·경관 등 특정빈집의 문제 유형에 근거. 모든 빈집이 위험하다는 판단이나 기간에 따른 비용 증가율은 아님. |
| 이행강제금 | 특정빈집 조치명령을 정당한 사유 없이 기한 내 미이행할 때 부과 가능 | 위 안내와 [농어촌정비법 제65조의5](https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1029383889). 소재지 적용 법률과 실제 명령을 개별 확인해야 함. 단순히 비워두면 즉시 부과된다는 표현이나 특정 금액의 전면 강조는 하지 않음. |
| 재산세 | 과세 대상인 집·땅에는 공실 상태여도 재산세 부과 가능 | [법제처 생활법령정보 재산세 안내](https://www.easylaw.go.kr/CSP/CnpClsMain.laf?ccfNo=4&cciNo=1&cnpClsNo=3&csmSeq=1259). 재산의 과세대상·실제 현황·사실상 소유자 원칙을 빈집 맥락으로 풀어 쓴 설명. 비과세·감면 및 개별 과세 조건 확인 필요. |

원문 링크와 범위 설명은 각 항목의 ‘근거 보기’에서 확인할 수 있다. 빈집의 실제 상태를 조회·분석해서 이 세 가지가 모두 해당한다고 표시하는 기능이 아니다.

검토 과정에서 2027년 시행 예정 개정 규정도 함께 검색되었으므로, 예정 법령의 내용을 현재 모든 소유자에게 적용하는 문구는 사용하지 않았다. 법률별 적용 지역과 시행일은 후속 개편 때 다시 확인한다.

## 서비스가 약속하는 범위

현재는 기록·확인사항·공식 지원 정보·견적 범위·다음 행동 안내와 무료 진단 신청이다. 실제 철거업체 계약·매칭, 지원금 신청 대행·선정 보장, 최종 견적·세액 확정, 공사 완료 대행을 제공한다고 쓰지 않는다. 협력사 계약과 운영 절차가 준비되면 그 제공 범위를 별도로 설명한다.

‘진단 받으면 철거해야 한다’는 결론은 강요하지 않는다. 매도·철거·보유 각각의 안내가 있다는 문구와 FAQ를 유지한다. 보유 자체와 위험한 상태를 확인 없이 방치하는 것을 동일하게 취급하지 않는다.

## 검증 기준

본문과 근거 펼침에서 모바일 가로 넘침·문구 잘림이 없어야 한다. 첫 화면의 주소 입력 폼이 한 번만 표시되고, 마지막 신청 버튼이 이 폼으로 이동해야 한다. 주소 확인과 다음 페이지 폼 흐름은 유지돼야 한다. 법적 책임·세금 감면·철거 절감의 실적을 이번 문구 변경으로 검증한 것은 아니다.

최초 구성 확인 결과: 배포용 빌드 통과. Chrome 320·375·390·768·1440px에서 기본·근거 펼침의 가로 넘침 없음, 근거 링크 4개 표시, 키보드 펼침, 시작 버튼의 주소 입력 이동 확인. 테스트 응답을 사용해 주소 확인 → `/apply` 입력 유지까지 확인했으며 실제 신청은 제출하지 않았다. 기존 큰 글씨 진단서의 20px 본문과 접근도 유지된다. 스크린샷·검사 결과·실행 스크립트는 `output/home-story-2026-09-12/`에 보관한다. 실제 휴대폰 또는 사용자 이해도 검증은 별도다.

첫 화면 폼 통합 후 확인: 배포용 빌드 통과. Chrome 320·390·768·1440px에서 폼 한 개만 표시, 집토끼와 폼 겹침 없음, 기본·주소 확인 카드·지도 표시 상태의 가로 넘침 없음. 테스트 주소·지도 응답으로 주소 수정 시 입력 포커스 복귀, 마지막 신청 버튼의 첫 화면 폼 이동, `/apply`로 확인 주소 전달을 점검했다. 실제 주소 조회나 신청 제출은 하지 않았다.

후킹 문구 반영 후 확인: 배포용 빌드 통과. Chrome 320·390·768·1440px에서 새 제목·설명·무료 확인 버튼, 가로 넘침과 폼 겹침 여부를 확인했다. 320·390·1440px 스크린샷에서 문단 간격과 집토끼 배치를 직접 검토했다. 테스트 주소·지도 응답으로 조회·주소 수정·`/apply` 전달과 하단 링크 이동을 확인했으며 실제 신청은 제출하지 않았다. 검사 스크립트와 이미지는 `/private/tmp/binzip-hook-copy-qa.mjs`, `/private/tmp/binzip-hook-copy-qa/`에 있다.
