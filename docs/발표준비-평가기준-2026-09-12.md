| 영역 | 빈집진단서에서 보여줄 구체적인 내용 |

| 지역 연계 | 포항의 실제 사례와 사용자 인터뷰, 포항 지원정보를 확인하는 경로를 연결. 지역 통계·기관 협력은 출처나 실제 협의가 있는 범위만 설명. |

차별성의 검증 질문: 공인중개사나 철거업체에 바로 문의하는 경우와 비교해, 이 자료가 어떤 반복 설명·자료 수집·추가 질문을 줄여 주는가?

## 남은 기간의 우선순위

1. **핵심 사용자 흐름의 완결성.** 대상 고객에 맞는 주택 사례로 조회부터 다음 행동 안내까지 확인한다. 2026-09-12 즉시 진단 문서의 실제 조회 검증 사례는 포항시청이므로, 이것만으로 시골 단독주택 사례 검증을 대신하지 않는다.
2. **짧은 관찰 근거.** 가능하면 실제 사용자에게 직접 입력하도록 하고 막힌 지점·완료 시간·이해한 다음 행동을 기록한다. 실무자에게 결과를 보여주어 빠진 정보와 줄어드는 질문을 확인한다. 실행 전에는 검증 계획으로만 발표한다.
3. **수익 가설 하나 구체화.** 예: 기본 조회는 무료, 추가 서류·사진을 정리한 상담 준비자료는 소유자에게 유료 제공. 이는 검토 후보이며 확정 BM이 아니다. 가격 실험과 작업당 사람의 소요 시간을 함께 확인한다.
4. **5분 리허설과 예상 질문.** 새 기능 확대보다 시연 연결과 설명의 정확도를 우선한다.

사진 AI 분석, 자동 견적, 빈집애 자동 등록, 중개사 매칭은 확장 아이디어다. 현재 시연의 필수 범위로 한꺼번에 추가하지 않는다.

## 시연에서 구분할 현재 상태

2026-09-12 프로젝트 문서 기준이며, 이 메모 작성 중 실시간 동작을 다시 시험한 결과는 아니다. 발표 전에는 실제 사용할 환경에서 다시 확인한다.

- 공적 기록 기반 1차 진단과 선택별 안내: 기존 즉시 진단 흐름. [구현·검증 기록](instant-diagnosis.md)
- 계산 예시: 가정값 또는 사용자 입력에 따른 계산. 실제 매도가·철거비의 자동 예측으로 소개하지 않음.
- 사진: 추가 확인 신청 흐름과 실제 저장·AI 분석을 구분. 즉시 진단 흐름에는 사진 AI 분석이 실행되지 않음.
- 관리자 미리보기: 가상 신청을 쓰는 화면. 실제 고객 접수·운영 실적으로 소개하지 않음. [관리자 화면 기록](admin-workbench.md)
- 빈집애 및 공인중개사 연결: 확장 후보. 자동 등록, 공식 제휴, 유료 수요는 미확인.

## 예상 질문과 답변의 기준

- **“왜 중개사에게 바로 가지 않나요?”** 상담 전에 확인할 자료와 질문을 준비한다는 가치를 설명하고, 실제로 줄어드는 일이 있는지 검증한 범위만 답한다.
- **“AI가 무엇을 하나요?”** 공공데이터 조회·규칙·계산·AI 처리를 구분해 실제 구현된 역할만 설명한다. 향후 사진 분석을 현재 기능으로 말하지 않는다.
- **“누가 돈을 내나요?”** 초기 유료 가설 하나와 제공 범위, 검증 방법을 답한다. 관리대행 수요를 못 찾은 인터뷰가 유료 진단 수요를 증명하지는 않는다.
- **“얼마나 개선됐나요?”** 관찰 인원과 측정 방법이 있는 결과만 제시한다. 결과가 없으면 측정 계획과 미검증 상태를 명확히 답한다.
