# 진단서 단일 예시 사례

> 후속 리뉴얼에서 주변 거래 사례와 철거 예산·진행 단계 목업을 추가했다. 현재 화면·상담 시연 범위는 [철거 진단서 흐름](demolition-report-flow.md)에 기록했다.

작성일: 2026-09-12

사용자가 지정한 주소는 **경상북도 포항시 남구 호미곶면 대보리 126-6**이다. 주소를 바탕으로 하나의 건물 사례를 구성하되, 실제 등기·건축물대장 조회를 수행한 것은 아니다. 아래 정보는 전부 서비스 시연을 위해 만든 데이터이며 해당 주소의 실제 소유자나 건물 상태를 나타내지 않는다.

## 사례 설정

| 항목 | 데이터 |
| --- | --- |
| 대지 | 지목 대, 198㎡ |
| 건물 | 1동, 지상 1층 단독주택, 목조·기와 |
| 건축면적·연면적 | 각각 56.2㎡ |
| 사용승인일 | 1985-04-18 |
| 소유자 | 소유자 A, 토지·건물 동일, 각 지분 1/1 |
| 취득 | 2018-03-16 상속 등기 |
| 갑구 | 압류·가압류·가처분 기재 없음 |
| 을구 | 토지·건물 공동담보 근저당권 1건, 채권최고액 600만 원, 금융기관 A |
| 대장 표시 | 위반건축물 표시 없음 |
| 소유자 설명 | 2021년부터 비어 있음, 타 지역 거주, 매도·철거 고민 |
| 서류 확인일 | 2026-09-12 |

서류에는 실명·주민등록번호·발급번호·관공서 직인 등을 만들지 않는다. 등기부와 건축물대장은 원본 이미지가 아닌 항목별 요약으로 표현한다.

## 비용과 확인 단계

- 계산기는 기존 두 선택지의 입력값을 사용한다. 그대로 매도 3,000만 원 − 채무 500만 원 − 세금·거래비용 200만 원 − 정리비용 100만 원 = 2,200만 원.
- 철거 후 매도 4,200만 원 − 채무 500만 원 − 세금·거래비용 250만 원 − 철거 등 정리비용 1,200만 원 = 2,250만 원.
- 채권최고액 600만 원과 소유자 입력 상환 예정액 500만 원은 서로 다른 항목이다. 실제 상환액과 말소 절차 확인을 다음 행동으로 둔다.
- 서류 확인은 완료된 상황이다. 현장 방문·사진·석면 조사, 개별 세금과 매수 수요는 완료로 처리하지 않는다.
- 공적 지원은 기존 공식 자료를 사용한다. 사례 내 소재지와 건축물 기록만 확인 상태이며, 선정·지원액·예산은 확정하지 않는다.

## 적용 범위

- `src/example-report-data.ts`: 두 예시 진단서가 공유하는 단일 사례·요약·다음 행동.
- `/example-report`, `/example-report/easy`: 최상단 안내 한 번, 주소와 기록 반영, 두 서류 요약 펼침. 검색엔진 색인 제외.
- 실제 `/apply` 신청이나 `/report/[id]`, 주소 조회 API, DB에는 이 사례를 주입하지 않는다. `ReportOverview`는 옵션으로 예시의 요약과 다음 행동을 받으며 기본 고객 동작은 유지한다.
- 예시 편집값은 저장되지 않는다. 사례의 서류·소유자 기록은 고정된 내용이고 계산기만 사용자가 바꿔볼 수 있다.

## 확인 기록

- 프로덕션 빌드 통과. 기존 계산기·고객 보고서 모델 테스트 8개 통과.
- 두 예시 경로의 320 / 390 / 1440px 화면에서 주소·면적·소유자 일치와 서류 펼침, 가로 넘침 없음 확인.
- ‘팔기’ 선택 후 등기 내역 이동, 키보드 펼침·닫힘, 인쇄 시 서류와 최상단 안내 유지 확인.
- 실제 `/apply` 주소는 자동 입력되지 않으며 예시 열람 중 API 조회·신청 제출 없음 확인.
- 검증 스크립트와 결과: `output/example-case-2026-09-12/`. 외부 폰트 지연에 대비한 테스트 제한 시간을 적용했고 최종 실행에서는 폰트 대체 처리 없이 통과했다.
