## 0. 왜 20명이 아니라 5명인가

kill criterion을 20명으로 잡으면 **12일 안에 발동하지 않는다.**
남은 벌초 주말은 9/12~13 하나뿐이고, 현실적 상한은 5~10명이다.
기준이 발동하지 않으면 발표는 "아직 검증 중"으로 끝난다.

**n=5에서는 비율을 측정할 수 없다.** "30%"의 신뢰구간이 너무 넓다.
대신 측정할 수 있는 것은 **만장일치**다. 5명이 같은 말을 하면
그 자체로 충분히 센 신호이고, 표본이 작을수록 이 판정이 더 유효하다.

그래서 모든 임계치를 **비율이 아니라 사람 수**로 쓴다.

## 1. 검증하는 가설

| | 가설 | 이번에 보나 |
|---|---|---|
| A | 매입 전 리스크 판독에 돈을 낸다 | **아니오** — §6 참조 |
| B | 보유 후 자산관리에 지속 관계가 생긴다 | 예 |
| C | 판단 레이어(무엇을 확인해야 하는지)에 가치가 있다 | **예 — 이번의 핵심** |
| D | 지속 모니터링에 돈을 낸다 | 신호만 |
| E | 현장관리까지 가면 recurring 이 생긴다 | 아니오 |

**이번 5명으로 판정하는 것은 C 하나다.** C가 죽으면 B·D·E가 다 죽는다.
C가 살면 그때 D를 따로 본다.

### Killer Question

> 주소 하나로, 소유주가 **몰랐던 중요한 사실을 하나라도** 찾아줄 수 있는가.

## 2. 🔴 측정 방법 — 자기보고를 쓰지 않는다

**"몰랐던 정보가 있었나요?"라고 물으면 안 된다.** 예의상 "네"가 나온다.
이 한 가지 실수로 전체 검증이 무의미해진다.

### 순서를 뒤집는다

```
① 진단서를 보여주기 「전에」 먼저 받는다
     "이 집에 대해 알고 계신 걸 말씀해 주세요."
     → 받아 적는다. 유도하지 않는다. 침묵을 견딘다.

② 진단서를 보여준다

③ 차이를 「관찰」한다
     ①에서 안 나왔는데 ②에 있는 항목 = 몰랐던 정보
     응답자에게 세어달라고 하지 않는다. 내가 센다.
```

①에서 응답자가 먼저 말한 항목만 "알고 있던 것"으로 친다.
진단서를 보고 *"아 그건 알았어요"* 하는 건 **몰랐던 것으로 센다.**
사후 합리화는 배제한다.

### 반응도 기록한다

말보다 반응이 정직하다. 다음이 나오면 표시한다.

```
□ 화면을 다시 봄 / 손가락으로 짚음
□ "어?" "이게 뭐야" 같은 즉각 반응
□ 사진을 찍거나 캡처를 요청함
□ 가족·배우자에게 보여주겠다고 함
□ 그 자리에서 다른 질문을 함
```

## 3. 판정 기준 — 5명

### 3.1 KILL — 하나라도 걸리면 C 가설 축소·폐기

| # | 신호 | 뜻 |
|---|---|---|
| K1 | **4명 이상**이 몰랐던 정보 0건 | 판단 레이어에 가치 없음 |
| K2 | **3명 이상**이 주소 입력 자체를 안 함 | 관심 자체가 없음 |
| K3 | **0명**이 "계속 받아보고 싶다" | 지속 관계 불가 |
| K4 | **4명 이상**이 "이미 인터넷에서 볼 수 있는 것" 취지로 말함 | 단순 aggregation 으로 인식됨 |

K1·K4가 동시에 걸리면 **B·D·E까지 함께 접는다.**

### 3.2 GO — 세 개 중 둘 이상이면 계속

| # | 신호 |
|---|---|
| G1 | **3명 이상**이 몰랐던 정보 1건 이상 발견 |
| G2 | **2명 이상**이 후속 행동을 구체적으로 말함 (등기 열람 / 시청 문의 / 현장 확인 / 수리 견적) |
| G3 | **1명 이상**이 묻지 않았는데 먼저 돈 이야기를 꺼냄 |

**G3이 나오면 그 사람과 30분 더 붙는다.** 5명 중 자발적 WTP 1건은
20명 중 유도된 WTP 6건보다 값이 크다.

### 3.3 AMBIGUOUS — 그 사이

`KILL`도 `GO`도 아니면 **판정하지 않는다.**
"애매하다"를 결과로 인정하고 표본을 더 모은다.
억지로 한쪽으로 읽지 않는다 — 그게 이 문서를 쓰는 이유다.

## 4. 물어볼 것 — 5개면 충분하다

### Q1. 사전 지식 (진단서 보여주기 전)

> "이 집에 대해 알고 계신 걸 말씀해 주세요."

받아 적기만 한다. **되묻지 않는다.** 항목을 제시하지 않는다.

### Q2. 반응 (진단서 보여준 직후, 30초 침묵)

먼저 말하기를 기다린다. 침묵이 길어도 먼저 설명하지 않는다.
첫마디를 그대로 기록한다.

### Q3. 후속 행동

> "이걸 보시고 나면 뭘 하실 것 같으세요?"

*"글쎄요"*도 유효한 답이다. 유도하지 않는다.

### Q4. 지속

> "이 집에 뭔가 바뀌는 게 있으면 알려드릴까요? 어떤 게 바뀌면 알고 싶으세요?"

**뒷부분이 핵심이다.** "알려주세요"는 공짜니까 다 그렇다고 한다.
**무엇을** 알고 싶은지가 진짜 니즈다. 답이 구체적일수록 신호가 세다.

### Q5. WTP — 🔴 금액을 먼저 말하지 않는다

> ❌ "월 4,900원이면 쓰시겠어요?"
> ✅ **"이 집 때문에 지금까지 돈을 쓰신 적 있으세요? 얼마나요?"**

**과거 지출이 미래 지불의사보다 훨씬 정직하다.**
재산세·관리비·수리비·왕복 교통비·대행 수수료 — 이미 쓰고 있는 돈이
있으면 그 옆에 우리 가격을 놓을 자리가 생긴다. 없으면 없는 것이다.

그 다음에만 묻는다 —

> "무료가 아니라면, 어떤 경우에 돈을 낼 만하다고 보세요?"

선택지를 **주지 않는다.** 월 구독 / 연간 건강검진 / 건별 정밀분석 /
현장관리 중 어디로 몰리는지 **응답자가 먼저 말하게** 둔다.

## 5. 🔴 착수 전 필수 — 실거래가 어댑터

**지금 상태로 인터뷰하면 잘못된 kill 판정이 나온다.**

Killer Question 의 재료 중 "몰랐던 정보"에 가장 크게 기여할 항목은
**주변 거래**다. 사람들이 자기 집에 대해 제일 모르는 건 법적 상태가
아니라 "얼마인가"다. 그런데 지금 그 데이터가 없다.

```
지금 만들 수 있는 것    건축물 / 용도지역 / 진입로 / 공시가격 / 규제 / 등기(사람)
지금 못 만드는 것       ⚠️ 주변 실거래
                        ⚠️ 다필지 구성
                        ⚠️ 필지 단위 진입로 분석
```

**국토부 실거래가 API 는 공개이고 무료다.** 어댑터 하나면 된다.
다필지·진입로 분석보다 훨씬 싸고 효과가 크다.

- [ ] **실거래가 어댑터 — 인터뷰 시작 전에 반드시 붙인다**

이걸 빼고 나온 K1(몰랐던 정보 0건)은 **가설이 틀린 게 아니라 재료가 없는 것**이다.
그 판정은 믿지 않는다.

## 6. 가설 A를 이번에 안 보는 이유

경매 전 리스크 판독은 pain 이 더 강하다. 그래서 매력적이다.
그럼에도 이번 12일에는 넣지 않는다.

| | 이유 |
|---|---|
| **데이터** | 법원경매정보에 공개 API 가 없다. 지역 게이트도 전국으로 풀어야 한다 |
| **룰** | 유치권·대항력·배당 — 관련 룰이 하나도 없다 |
| **법적 선** | **권리분석을 유상 제공하면 법무사법상 무자격 법률사무에 걸릴 수 있다.** 세무사법 §2 와 같은 구조다 |
| **책임** | 낙찰가가 수천만~수억이다. B는 "확인해보세요"로 끝나지만 A는 "입찰해도 됩니다"에 가까워진다 |

**A는 pain 이 강한 만큼 책임도 크다.** 그게 MVP 로 먼저 갈 자리가 아닌 이유다.
발표에서는 "다음 가설"로 말하고, 테스트는 이후에 한다.

병행하면 둘 다 반쯤 된 상태로 9/18을 맞는다.

## 7. North Star — 정의를 고친다

기존 초안의 ③이 자기충족적이었다.

> ~~③ 90일 이내 데이터 갱신/상태점검이 이루어진 자산~~

**갱신을 자동으로 하면 cron 이 돌 때마다 전 자산이 조건을 만족한다.**
지표가 100%로 고정되고 아무것도 측정하지 않는다.
사람이 하면 그건 지표가 아니라 비용 함수다.

측정하려는 건 "우리가 뭔가 했다"가 아니라 **"사용자가 관계를 유지한다"**다.

```
Managed Properties

  ① baseline 이 등록되어 있고
  ② 모니터링이 활성화되어 있으며
  ③ 지난 갱신 알림을 열었거나, 자산 정보를 수정했거나,
     해지하지 않은 상태로 갱신을 1회 이상 통과한 자산
```

부동산은 매달 뭔가 할 필요가 없는 자산이다. 그래서 더더욱
**"안 떠난 것"이 유일한 유효 신호**다. 해지율의 역수에 가깝게 정의하는 게 정직하다.

②도 등록 시 기본값이 켜져 있으면 ① = ②가 된다. **기본값을 꺼두고
사용자가 켜게 한다.** 그래야 §3.1의 K3가 의미를 갖는다.

## 8. TAM/SAM — 쓸 수 있는 공식 통계

소유 개수 기반 segmentation 은 폐기한다. **거리로 자른다.**

통계청 주택소유통계에 소재지 기준 소유자 거주지 분포가 있다.

```
주택 소재지와 소유자 거주지가 같은 비중
   시·도 기준     86.4%   →  타 시·도 거주   13.6%
   시·군·구 기준   76.2%   →  타 시·군·구 거주 23.8%
```

**"자산과 소유주의 물리적 거리가 멀다"와 정확히 맞는 유일한 공식 통계다.**

```
1,597.6만 × 13.6%  ≈  217만    ← SAM 상단으로 쓴다 (보수적)
1,597.6만 × 23.8%  ≈  380만    ← 강남↔서초도 포함돼 과대
```

여기서 비아파트·저가·상속 조건으로 좁혀 내려가면 bottom-up 이 된다.

- [ ] **위 수치가 주택 수 기준인지 소유자 수 기준인지 확인** —
