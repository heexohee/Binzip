# 진단서 구조와 목업

작성 2026-09-09 · 브랜치 `feat/demolition-scenario`
상위 문서 `docs/설계-2차-진단서와-행동경로.md` (6항목·6경로 기준 — 이 문서가 대체한다)

> **한 줄** — 기존 진단서(4축)는 그대로 두고, 그 위에 **3시나리오 비교**를 얹는다.
> 4축은 "무엇이 걸려 있나", 3시나리오는 "그래서 어떻게 할 것인가"다.

---

## 0. 왜 이 구조인가

빈집 소유자가 실제로 답을 원하는 질문은 하나다.

> **"이 집을 어떻게 해야 하나?"**

기존 진단서는 *"무엇이 걸려 있나"*까지만 답했다. 그건 재료이지 답이 아니다.
그리고 소유주가 고르는 선택지는 셋뿐이고, **셋은 서로 배타적이다** —
철거비 지원을 받으면 공공활용 의무가 붙어 그 기간에는 팔 수 없다.

그래서 나열이 아니라 **같은 잣대의 비교**가 필요하다.

---

## 1. 전체 구조

```
1페이지 ─────────────────────────────────────────  ✅ 구현 완료
  헤더        주소 · 문서번호 · 확인일 · 작성자
  판정        가능 / 조건부 / 선행필요 / 불가        4등급
  4축         ① 권리  ② 세금  ③ 건물·토지  ④ 시장·관리
              └ 목업의 「확인된 문제」가 여기 해당한다

2페이지 ─────────────────────────────────────────
  3시나리오    ① 그대로 둔다 / ② 철거한다 / ③ 고쳐서 쓴다   ✅ 구현 완료
  이용 가능한 제도                                        ⬜ 목업
  추천 순서                                              ⬜ 목업
  전문가 연결                                            ⬜ 목업
```

**1페이지는 건드리지 않는다.** 4축이 시나리오 판단의 근거이기 때문이다.
예를 들어 ③건물·토지의 「슬레이트」가 잡혀야 ②철거의 지원금 700만원이 나온다.

## 2. 구현된 것 — 3시나리오 비교

`src/tax.ts` 의 `compareScenarios()`, `src/report-view.ts` 의 `buildPaths()`.

공시 6,080만원 · 계획관리지역 · 27년 · 슬레이트 지붕 필지의 실제 출력:

```
먼저 — 권리관계 확인          (권리가 안 풀렸을 때만 나온다)
   등기부를 확인하기 전에는 아래 셋 중 무엇도 진행할 수 없습니다.
   인터넷등기소 열람 수수료는 700원입니다.

① 그대로 둔다
   보유세는 연 1.6만원 수준입니다 (1주택 기준·추정).
   다른 집이 있으시면 4.4만원입니다.
   특정빈집으로 판정되어 조치명령을 받고 이행하지 않으면 이행강제금이 부과됩니다.

② 철거한다
   철거하면 보유세가 연 5.1만원이 되고, 감면이 끝나면 10.2만원입니다.
   ⚠️ 주택분에서 토지분으로 넘어가 보유세가 오히려 오를 수 있습니다.
      과세표준 비율이 60%에서 70%로 오르고 세율도 높아집니다.
   ⚠️ 1세대1주택이시면 부담이 더 큽니다. 특례세율(0.05%)은 주택에만 있고
      토지에는 없어, 철거하는 순간 그 혜택을 잃습니다.
   ⚠️ 철거비 지원(최대 1,600만원)을 받으면 그 땅을 일정 기간 주차장·텃밭 등
      공공용도로 써야 합니다. 그 기간에는 팔 수 없습니다.
   슬레이트 지붕이라 처리 지원 최대 700만원을 별도로 받을 수 있습니다.
   신청은 빈집애(binzibe.kr)에서 합니다.

③ 고쳐서 쓴다
   사용승인으로부터 27년 지났습니다.
   보유세는 1.6만원으로 그대로입니다. 주택으로 남기 때문입니다.
   연면적 200㎡ 미만이고 3층 미만이면 대수선은 허가가 아니라 신고로 됩니다.
```

### ②의 경고 두 줄이 이 제품의 존재 이유다

```
빈집 유지    주택 분류   과표 60%  ·  주택 세율 (1주택 특례 0.05%)
철거 후      나대지     과표 70%  ·  종합합산 0.2~0.5%  (특례 없음)

배율   1주택 6.5배   ·   표준 2.3배
```

인천·전주에서 실제 2~3배 증가 사례가 확인됐다(표준 기준).
**1주택자는 특례세율을 잃어 배율이 더 크다.** 이건 아무도 안 알려준다.

세율 출처 — 지방세법 §111 종합합산 2/3/5‰, 별도합산 2/3/4‰,
분리과세 농지·임야 0.7‰. 토지 공정시장가액비율 70%. 원문 대조 완료.

## 3. ⬜ 목업 — 현재 이용 가능한 제도

시나리오 ②·③ 아래에 붙는다. **자산 조건에 따라 해당되는 것만 낸다.**

```
┌ 현재 이용 가능한 제도 ────────────────────────────────┐
│                                                      │
│  빈집 철거비 지원                        최대 1,600만원 │
│    중앙 50% + 지자체 50%                              │
│    ⚠️ 철거 후 일정 기간 주차장·텃밭 등 공공용도 의무      │
│    신청  빈집애(binzibe.kr) · 2026-05-25 온라인 개시    │
│                                                      │
│  슬레이트 처리 지원                        최대 700만원 │
│    비주택(창고·축사)은 540만원                          │
│    신청  시군구청 환경·건축 부서                        │
│                                                      │
│  철거 후 재산세 감면                      5년간 50%     │
│    2026-01-01 시행                                    │
│                                                      │
│  철거 후 3년 내 신축 취득세 감면      최대 50%·150만원 한도│
│                                                      │
└──────────────────────────────────────────────────────┘
```

### 판정 규칙 (구현 시)

| 제도 | 조건 |
|---|---|
| 철거비 지원 | `hasBuilding === true` · 개인 소유 |
| 슬레이트 처리 | `structure` 에 '슬레이트' 포함 · 주택/비주택 금액 분기 |
| 재산세 감면 | 철거 시나리오에서만 |
| 취득세 감면 | 철거 + 신축 의사가 있을 때만 |

## 4. ⬜ 목업 — 추천 순서

**지금은 못 만든다.** §6의 미확인 값이 채워져야 "어느 게 낫다"를 말할 수 있다.

```
┌ 추천 순서 ────────────────────────────────────────────┐
│                                                      │
│  ① 등기 확인          상속·공유 정리 여부              │
│         ↓                                            │
│  ② 매각 의향 확인      ← 철거지원보다 「먼저」           │
│         ↓             지원받으면 공공용도 의무로 못 팜   │
│  ③ 철거지원 대상 여부   시청 문의                       │
│         ↓                                            │
│  ④ 지원 불가 시 철거비 견적                            │
│                                                      │
└──────────────────────────────────────────────────────┘
```

### ⚠️ 순서가 목업 초안과 다르다

처음 목업은 `① 권리 → ② 철거지원 → ③ 견적 → ④ 매각 비교` 였다.
**②와 ④가 바뀌어야 한다.**

철거비 지원에 **공공활용 의무**가 붙기 때문이다. 팔 생각이 있으면
지원을 받으면 안 된다. 즉 **매각 의향이 지원 신청보다 먼저 와야 한다.**

이걸 거꾸로 안내하면 소유주가 1,600만원을 받고 나서
"이제 못 판다"는 걸 알게 된다. 그건 우리가 만든 피해다.

## 5. ⬜ 목업 — 전문가 연결

각 버튼이 **왜 이 전문가가 필요한지**를 먼저 말한다. 광고판이 아니다.

```
① 권리에 미확인이 있으면      →  [법무사 — 상속등기·보존등기]
② 철거를 고르면              →  [철거업체 견적]  [시청 지원사업 문의]
③ 정비를 고르면              →  [건축사 상담]
매각 의향이 있으면            →  [공인중개사 매각 상담]
처분세가 걸리면              →  [세무사 상담]
```

**연결 전에 "이 집은 왜 이 전문가가 필요한가"를 한 줄로 설명한다.**
예: *"토지와 건물의 소유자가 달라 보입니다. 법무사 확인이 필요합니다."*

BM 상 이 지점이 수익 발생점이지만, **MVP에서는 버튼과 문구만 두고
실제 연결·수수료는 붙이지 않는다.** 검증 전에 붙이면 광고판이 된다.

포항시 공동주택과 주택정비팀   054-270-3608

| # | 물어볼 것 | 왜 필요한가 |
|---|---|---|
| 1 | **철거 지원 받으면 그 땅을 몇 년간 못 파나요?** | §4 추천 순서의 승패를 가름. 5년이면 감면과 맞물리고 10년이면 사실상 매각 포기 |

## 7. 구현 순서

```
✅  1  3시나리오 비교           tax.ts · report-view.ts
⬜  2  「이용 가능한 제도」 블록   §3 — 미확인 값 없이도 만들 수 있다
⬜  3  진단서 화면에 렌더        report-doc.tsx
⬜  4  「추천 순서」             ← §6 의 1·2번이 채워진 뒤에
⬜  5  「전문가 연결」 버튼       문구만. 실제 연결은 검증 후
```

**2·3은 지금 할 수 있다.** 4는 전화 뒤에 한다 —
지금 만들면 "어느 게 낫다"를 근거 없이 말하게 된다.

## 8. 지금 남아 있는 불일치

```
랜딩    "포항에 있는 빈집"
게이트   경북 전체 (^47)
```

말과 판정이 다르다. 셋 중 하나를 골라야 한다.

| | |
|---|---|
| 포항으로 좁힌다 | 게이트를 `47111\|47113` 으로. 경주 필지가 다시 막힌다 |
| 경북 유지, 문구만 포항 | 지금 상태. 포항에 말 걸되 경주도 받는다 |
| 경북이라고 말한다 | 헤더를 "경북에 있는 빈집"으로 |

철거 지원·슬레이트 지원은 전국 사업이라 포항으로 좁힐 근거가 약하다.
다만 *"집 앞까지 직접 가서 확인합니다"* 를 지키려면 이동 거리 문제가 생긴다.
**운영 부담의 문제이지 기술 문제가 아니다.**
