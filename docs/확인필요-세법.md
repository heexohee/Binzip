## 0. 무엇을 하려는 것인가

②세금축은 두 가지를 말한다.

| | MVP에서 | 이유 |
|---|---|---|
| **재산세 (보유)** | ✅ 자동 계산해서 **숫자로** 제시 | 공시가격만 있으면 계산된다 |
| **양도세 (처분)** | ⚠️ 체크포인트 **서술만**, 계산 안 함 | 세무사법 §2 — 유상 세무대리 금지선 |

**핵심 메시지는 안심이다.** 소유주는 "재산세가 계속 나간다"를 막연한 공포로 갖고 있는데
실제로는 연 몇 만원이다. 이걸 숫자로 보여주면 *"보유해도 싸다, 방치가 비싸다"*가 된다.
그래서 **재산세 숫자가 정확해야 한다** — 이 문서의 존재 이유다.

## 1. 🔴 재산세 — 반드시 확인 (매년 바뀜)

### 1.1 계산 구조

```
과세표준 = 공시가격 × 공정시장가액비율
재산세   = 과세표준 × 세율  +  지방교육세(본세의 20%)  [+ 도시지역분]
```

이 구조 자체는 확실하다. **아래의 비율과 세율만** 확인하면 된다.

### 1.2 확인할 값

| # | 항목 | 설계에 쓴 값 | 근거 조문 | 확인값 |
|---|---|---|---|---|
| 1 | 공정시장가액비율 — 1세대1주택 (공시 3억 이하) | **43%** | 지방세법 시행령 §109 | |
| 2 | 공정시장가액비율 — 1세대1주택 (3~6억) | **44%** | 같음 | |
| 3 | 공정시장가액비율 — 1세대1주택 (6억 초과) | **45%** | 같음 | |
| 4 | 공정시장가액비율 — 표준(다주택·법인) | **60%** | 같음 | |
| 5 | 1주택 특례세율 적용 상한 | 공시 **9억** 이하 | 지방세법 §111의2 | |
| 6 | 지방교육세율 (재산세 본세 대비) | **20%** | 지방세법 §151 | |
| 7 | 도시지역분 요율 (과세표준 대비) | **0.14%** | 지방세법 §112 | |

### 1.3 세율표 — 1세대1주택 특례 (지방세법 §111의2)

| 과세표준 구간 | 설계에 쓴 세율 | 누적 기준액 | 확인값 |
|---|---|---|---|
| 6,000만원 이하 | 0.05% | 0 | |
| 6,000만 ~ 1억 5,000만 | 0.10% | 30,000원 | |
| 1억 5,000만 ~ 3억 | 0.20% | 120,000원 | |
| 3억 초과 | 0.35% | 420,000원 | |

### 1.4 세율표 — 표준 (지방세법 §111 주택)

| 과세표준 구간 | 설계에 쓴 세율 | 누적 기준액 | 확인값 |
|---|---|---|---|
| 6,000만원 이하 | 0.10% | 0 | |
| 6,000만 ~ 1억 5,000만 | 0.15% | 60,000원 | |
| 1억 5,000만 ~ 3억 | 0.25% | 195,000원 | |
| 3억 초과 | 0.40% | 570,000원 | |

> **누적 기준액이란** — 구간 시작점까지의 누적 세액이다.
> 예: 과세표준 1억이면 `60,000 + (1억 − 6,000만) × 0.15% = 120,000원`.

### 1.5 ⭐ 가장 빠른 검증법 — 위택스 대조

**값을 하나하나 찾기 전에 이것부터 하면 한 번에 판가름 난다.**

1. **위택스 → 지방세 미리계산 → 재산세(주택)**
2. 공시가격 **60,800,000원** 입력
3. 1세대1주택 / 다주택 두 경우로 각각 계산
4. 아래 설계 검산값과 비교

```
1세대1주택   과세표준 26,144,000 × 0.05% = 13,072  + 지방교육세 2,614  =  15,686원/년
표준         과세표준 36,480,000 × 0.10% = 36,480  + 지방교육세 7,296  =  43,776원/년
```

- **맞으면** → §1.2~1.4를 그대로 쓴다. 조문 확인 생략 가능.
- **틀리면** → 어느 단계에서 갈렸는지 역산한다. 과세표준이 다르면 §1.2의 비율,
  세액이 다르면 §1.3~1.4의 세율이 원인이다.

> 이 필지는 **계획관리지역**(비도시)이라 도시지역분이 붙지 않는다.
> 위택스에서도 도시지역분을 빼고 비교해야 한다.

## 2. 🟡 양도세 특례 — 요건 확인

**세액을 계산하지 않는다.** *"이 특례를 보시면 됩니다"*까지만 쓴다.
따라서 필요한 것은 계산식이 아니라 **적용 요건**이다.

### 2.1 농어촌주택 특례 (조특법 §99의4)

우리 타깃에 직접 걸리는데 **가장 불확실하다.**

- [ ] **상속으로 취득한 주택도 대상인가?** ← 제일 중요
      우리 신청자는 대부분 상속이다. 여기가 갈리면 진단서 문구가 완전히 달라진다.
- [ ] 취득 당시 기준시가 상한은 얼마인가
- [ ] 적용 기간 (취득 시점 요건)이 있는가 — 있다면 언제까지인가
- [ ] 보유 기간 요건 (3년?)
- [ ] 대상 지역 요건 — 수도권 밖 읍·면? 인구감소지역도 포함?
- [ ] **포항시 남구·북구가 대상 지역에 들어가는가** ← 안 들어가면 이 특례는 빼야 한다

### 2.2 상속주택 특례 (소득세법 시행령 §155②)

농어촌주택 특례보다 우리 케이스에 더 직접적이다.

- [ ] 상속개시 **당시** 일반주택을 보유하고 있어야 하는가
- [ ] 상속개시 후 취득한 일반주택은 제외되는가
- [ ] 공동상속주택일 때 누구의 주택으로 보는가 (지분 최다자? 거주자?)
- [ ] 선순위 상속주택 판정 기준

### 2.3 세컨드홈 특례

이전에 정리한 값이나 재확인 권장.

- [ ] 공시가격 상한 **4억원**이 맞는가
- [ ] 시행 시점이 **2027-01-01 취득분부터**가 맞는가
- [ ] 대상 지역에 포항이 포함되는가
- [ ] 매수인 기준인가 매도인 기준인가 (진단서에서는 **매물 설명**용으로 쓴다)

### 2.4 1세대1주택 비과세

- [ ] 보유 기간 요건 (2년?)
- [ ] 거주 기간 요건이 붙는 경우는 언제인가
- [ ] 포항이 조정대상지역인가 (아닐 것으로 보이나 확인)

## 3. 🟢 확인 불필요 — 이미 단단한 것

**다시 조사하지 마세요.** 시간 낭비입니다.

| 사실 | 근거 |
|---|---|
| 재산세 = 과세표준 × 세율 구조 | 지방세법 §110~111 |
| 지방교육세는 재산세 본세에 부가된다 | 지방세법 §150~151 |
| 도시지역분은 국토계획법상 **도시지역에만** 부과 | 지방세법 §112 |
| 계획관리·농림·자연환경보전지역은 **비도시지역** → 도시지역분 없음 | 국토계획법 §36 |
| 종합부동산세는 공시 1억짜리에 안 걸린다 (1주택 12억 / 일반 9억) | 종부세법 §8 |
| **세액 계산은 세무사법 §2의 세무대리에 해당** — 유상이면 명확히 걸린다 | 세무사법 §2 |
| 상속은 등기 없이 소유권 취득, **다만 처분하려면 등기 필요** | 민법 §187 |
| 법정지상권 — 경매로 토지·건물 소유자가 갈린 경우 | 민법 §366 |
| **대지권은 집합건물 개념. 단독주택에는 없다** | 집합건물법 §20 |
| 미등기 건물은 이전등기가 불가 → 사실상 매각 불가 | 부동산등기법 §65 |
| 매물 목록·지도 화면은 만들면 위법 | 공인중개사법 §18의2 |

## 6. 지켜야 할 선

조사하다 보면 넘고 싶어지는 지점들이다. **넘지 않는다.**

| 하지 않는다 | 이유 |
|---|---|
| 양도세 **세액** 계산 | 세무사법 §2. 무료 정보 제공은 회색이지만 **유상이면 검다** |
| "귀하의 세금은 X원입니다" | 위와 같음. 재산세도 반드시 **"추정"** 표기 |
| 폼에 문항 추가해서 양도세 자동화 | 9문항 유지. 실제 신청자 10건 받기 전에는 어느 분기에 몰리는지 알 수 없다 |
| 세법 분기를 미리 다 짜기 | YAGNI. 데이터 없이 설계하면 안 쓰이는 가지만 늘어난다 |

**수익은 세액 계산이 아니라 전문가 연결에서 낸다.**

```
빈집이력서(진단)  →  ①권리 미등기·상속미등기  →  법무사
                  →  ②처분세 체크포인트       →  세무사
                  →  ③슬레이트·구조           →  시공사
```

우리가 파는 것은 판단이 아니라 **진입점**이다. 자격 문제가 없다.

| 3 | 그냥 방치하면 부과되는 것처럼 읽힘 | **특정빈집 판정(§30) → 조치명령(§32) → 60일 미이행**이라야 부과 |

**3번이 가장 나쁘다.** 행정 절차 3단계를 거쳐야 하는 것을
"비워두면 돈 나옵니다"로 읽히게 써놨다. 근거 없이 소유주를 겁주는 문장이다.

### 고치면 메시지가 오히려 강해진다

```
재산세                              연  1.6만 ~ 4.4만원
이행강제금 (농어촌빈집특별법 §45)      연  최대 1,000만원   (500만원 × 연 2회 반복)
                                          ↑ 약 600배
```

그리고 **§32⑤** — 직권 철거 시 보상비에서 철거비를 빼고 지급하며,
**철거비가 보상비보다 많으면 차액을 추가 징수**한다.
방치 끝에 철거되면 돈을 받는 게 아니라 **낼 수도 있다.**

"보유해도 싸다 / 방치는 비싸다"의 근거가 허구였을 때보다 훨씬 세다.

### ⚠️ 설계에 없던 분기가 드러났다

두 법의 **관할이 배타적**이고(농어촌빈집특별법 §5, 빈집특례법 §3① 단서)
이행강제금 산정 방식이 완전히 다르다.

| 소재 | 근거 | 이행강제금 |
|---|---|---|
| **읍·면** | 농어촌빈집특별법 §45 | 500만원 이하 **정액** |
| **동** | 빈집특례법 §65 | 1㎡당 시가표준액 **50% × 연면적** 이하 |

**즉 진단서 문구가 주소에 따라 갈려야 한다.** 4축 설계에는 이 분기가 없다.
포항 남·북구 안에도 동이 있으므로 "시골이니까 읍·면"으로 뭉갤 수 없다.

`laws.json`의 `/위계/해소됨/새발견`에 더 까다로운 구간이 적혀 있다 —
**2027-06-17부터 준농어촌 빈집이 빈집특례법으로 편입**되므로
읍·면/동 이분법만으로 판별하면 이 구간을 놓친다.

반영할 곳 — 설계서에 분기 조건으로 추가하고,
계획서 Task 6(`관리 부담` 항목)·Task 7(`manage` 경로)에 주소 기반 분기를 넣는다.

### 용어 하나 더

`laws.json` 농어촌빈집특별법 §2제2호 메모 —
**법적 '빈집'은 지자체 확인이 있어야 성립한다.** 신청자가 비어 있다고 해도
아직 법적 빈집이 아니므로 **진단서 본문은 '이 주택'으로 쓴다.**
문서·코드에서 소유주에게 나가는 문장에 '빈집'을 쓰지 않았는지 함께 확인할 것.
