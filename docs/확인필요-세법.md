## 0. 무엇을 하려는 것인가

②세금축은 두 가지를 말한다.

| | MVP에서 | 이유 |
|---|---|---|
| **재산세 (보유)** | ✅ 자동 계산해서 **숫자로** 제시 | 공시가격만 있으면 계산된다 |
| **양도세 (처분)** | ⚠️ 체크포인트 **서술만**, 계산 안 함 | 세무사법 §2 — 유상 세무대리 금지선 |

**핵심 메시지는 안심이다.** 소유주는 "재산세가 계속 나간다"를 막연한 공포로 갖고 있는데
실제로는 연 몇 만원이다. 이걸 숫자로 보여주면 *"보유해도 싸다, 방치가 비싸다"*가 된다.
그래서 **재산세 숫자가 정확해야 한다** — 이 문서의 존재 이유다.

## 1. 🔴 재산세 — 반드시 확인 (매년 바뀜)

### 1.1 계산 구조

```
과세표준 = 공시가격 × 공정시장가액비율
재산세   = 과세표준 × 세율  +  지방교육세(본세의 20%)  [+ 도시지역분]
```

이 구조 자체는 확실하다. **아래의 비율과 세율만** 확인하면 된다.

### 1.2 확인할 값

| # | 항목 | 설계에 쓴 값 | 근거 조문 | 확인값 |
|---|---|---|---|---|
| 1 | 공정시장가액비율 — 1세대1주택 (공시 3억 이하) | **43%** | 지방세법 시행령 §109 | |
| 2 | 공정시장가액비율 — 1세대1주택 (3~6억) | **44%** | 같음 | |
| 3 | 공정시장가액비율 — 1세대1주택 (6억 초과) | **45%** | 같음 | |
| 4 | 공정시장가액비율 — 표준(다주택·법인) | **60%** | 같음 | |
| 5 | 1주택 특례세율 적용 상한 | 공시 **9억** 이하 | 지방세법 §111의2 | |
| 6 | 지방교육세율 (재산세 본세 대비) | **20%** | 지방세법 §151 | |
| 7 | 도시지역분 요율 (과세표준 대비) | **0.14%** | 지방세법 §112 | |

### 1.3 세율표 — 1세대1주택 특례 (지방세법 §111의2)

| 과세표준 구간 | 설계에 쓴 세율 | 누적 기준액 | 확인값 |
|---|---|---|---|
| 6,000만원 이하 | 0.05% | 0 | |
| 6,000만 ~ 1억 5,000만 | 0.10% | 30,000원 | |
| 1억 5,000만 ~ 3억 | 0.20% | 120,000원 | |
| 3억 초과 | 0.35% | 420,000원 | |

### 1.4 세율표 — 표준 (지방세법 §111 주택)

| 과세표준 구간 | 설계에 쓴 세율 | 누적 기준액 | 확인값 |
|---|---|---|---|
| 6,000만원 이하 | 0.10% | 0 | |
| 6,000만 ~ 1억 5,000만 | 0.15% | 60,000원 | |
| 1억 5,000만 ~ 3억 | 0.25% | 195,000원 | |
| 3억 초과 | 0.40% | 570,000원 | |

> **누적 기준액이란** — 구간 시작점까지의 누적 세액이다.
> 예: 과세표준 1억이면 `60,000 + (1억 − 6,000만) × 0.15% = 120,000원`.

### 1.5 ⭐ 가장 빠른 검증법 — 위택스 대조

**값을 하나하나 찾기 전에 이것부터 하면 한 번에 판가름 난다.**

1. **위택스 → 지방세 미리계산 → 재산세(주택)**
2. 공시가격 **60,800,000원** 입력
3. 1세대1주택 / 다주택 두 경우로 각각 계산
4. 아래 설계 검산값과 비교

```
1세대1주택   과세표준 26,144,000 × 0.05% = 13,072  + 지방교육세 2,614  =  15,686원/년
표준         과세표준 36,480,000 × 0.10% = 36,480  + 지방교육세 7,296  =  43,776원/년
```

- **맞으면** → §1.2~1.4를 그대로 쓴다. 조문 확인 생략 가능.
- **틀리면** → 어느 단계에서 갈렸는지 역산한다. 과세표준이 다르면 §1.2의 비율,
  세액이 다르면 §1.3~1.4의 세율이 원인이다.

> 이 필지는 **계획관리지역**(비도시)이라 도시지역분이 붙지 않는다.
> 위택스에서도 도시지역분을 빼고 비교해야 한다.

## 2. 🟡 양도세 특례 — 요건 확인

**세액을 계산하지 않는다.** *"이 특례를 보시면 됩니다"*까지만 쓴다.
따라서 필요한 것은 계산식이 아니라 **적용 요건**이다.

### 2.1 농어촌주택 특례 (조특법 §99의4)

우리 타깃에 직접 걸리는데 **가장 불확실하다.**

- [ ] **상속으로 취득한 주택도 대상인가?** ← 제일 중요
      우리 신청자는 대부분 상속이다. 여기가 갈리면 진단서 문구가 완전히 달라진다.
- [ ] 취득 당시 기준시가 상한은 얼마인가
- [ ] 적용 기간 (취득 시점 요건)이 있는가 — 있다면 언제까지인가
- [ ] 보유 기간 요건 (3년?)
- [ ] 대상 지역 요건 — 수도권 밖 읍·면? 인구감소지역도 포함?
- [ ] **포항시 남구·북구가 대상 지역에 들어가는가** ← 안 들어가면 이 특례는 빼야 한다

### 2.2 상속주택 특례 (소득세법 시행령 §155②)

농어촌주택 특례보다 우리 케이스에 더 직접적이다.

- [ ] 상속개시 **당시** 일반주택을 보유하고 있어야 하는가
- [ ] 상속개시 후 취득한 일반주택은 제외되는가
- [ ] 공동상속주택일 때 누구의 주택으로 보는가 (지분 최다자? 거주자?)
- [ ] 선순위 상속주택 판정 기준

### 2.3 세컨드홈 특례

이전에 정리한 값이나 재확인 권장.

- [ ] 공시가격 상한 **4억원**이 맞는가
- [ ] 시행 시점이 **2027-01-01 취득분부터**가 맞는가
- [ ] 대상 지역에 포항이 포함되는가
- [ ] 매수인 기준인가 매도인 기준인가 (진단서에서는 **매물 설명**용으로 쓴다)

### 2.4 1세대1주택 비과세

- [ ] 보유 기간 요건 (2년?)
- [ ] 거주 기간 요건이 붙는 경우는 언제인가
- [ ] 포항이 조정대상지역인가 (아닐 것으로 보이나 확인)

## 3. 🟢 확인 불필요 — 이미 단단한 것

**다시 조사하지 마세요.** 시간 낭비입니다.

| 사실 | 근거 |
|---|---|
| 재산세 = 과세표준 × 세율 구조 | 지방세법 §110~111 |
| 지방교육세는 재산세 본세에 부가된다 | 지방세법 §150~151 |
| 도시지역분은 국토계획법상 **도시지역에만** 부과 | 지방세법 §112 |
| 계획관리·농림·자연환경보전지역은 **비도시지역** → 도시지역분 없음 | 국토계획법 §36 |
| 종합부동산세는 공시 1억짜리에 안 걸린다 (1주택 12억 / 일반 9억) | 종부세법 §8 |
| **세액 계산은 세무사법 §2의 세무대리에 해당** — 유상이면 명확히 걸린다 | 세무사법 §2 |
| 상속은 등기 없이 소유권 취득, **다만 처분하려면 등기 필요** | 민법 §187 |
| 법정지상권 — 경매로 토지·건물 소유자가 갈린 경우 | 민법 §366 |
| **대지권은 집합건물 개념. 단독주택에는 없다** | 집합건물법 §20 |
| 미등기 건물은 이전등기가 불가 → 사실상 매각 불가 | 부동산등기법 §65 |
| 매물 목록·지도 화면은 만들면 위법 | 공인중개사법 §18의2 |

## 6. 지켜야 할 선

조사하다 보면 넘고 싶어지는 지점들이다. **넘지 않는다.**

| 하지 않는다 | 이유 |
|---|---|
| 양도세 **세액** 계산 | 세무사법 §2. 무료 정보 제공은 회색이지만 **유상이면 검다** |
| "귀하의 세금은 X원입니다" | 위와 같음. 재산세도 반드시 **"추정"** 표기 |
| 폼에 문항 추가해서 양도세 자동화 | 9문항 유지. 실제 신청자 10건 받기 전에는 어느 분기에 몰리는지 알 수 없다 |
| 세법 분기를 미리 다 짜기 | YAGNI. 데이터 없이 설계하면 안 쓰이는 가지만 늘어난다 |

**수익은 세액 계산이 아니라 전문가 연결에서 낸다.**

```
빈집이력서(진단)  →  ①권리 미등기·상속미등기  →  법무사
                  →  ②처분세 체크포인트       →  세무사
                  →  ③슬레이트·구조           →  시공사
```

우리가 파는 것은 판단이 아니라 **진입점**이다. 자격 문제가 없다.

| 3 | 그냥 방치하면 부과되는 것처럼 읽힘 | **특정빈집 판정(§30) → 조치명령(§32) → 60일 미이행**이라야 부과 |

**3번이 가장 나쁘다.** 행정 절차 3단계를 거쳐야 하는 것을
"비워두면 돈 나옵니다"로 읽히게 써놨다. 근거 없이 소유주를 겁주는 문장이다.

### 고치면 메시지가 오히려 강해진다

```
재산세                              연  1.6만 ~ 4.4만원
이행강제금 (농어촌빈집특별법 §45)      연  최대 1,000만원   (500만원 × 연 2회 반복)
                                          ↑ 약 600배
```

그리고 **§32⑤** — 직권 철거 시 보상비에서 철거비를 빼고 지급하며,
**철거비가 보상비보다 많으면 차액을 추가 징수**한다.
방치 끝에 철거되면 돈을 받는 게 아니라 **낼 수도 있다.**

"보유해도 싸다 / 방치는 비싸다"의 근거가 허구였을 때보다 훨씬 세다.

### ⚠️ 설계에 없던 분기가 드러났다

두 법의 **관할이 배타적**이고(농어촌빈집특별법 §5, 빈집특례법 §3① 단서)
이행강제금 산정 방식이 완전히 다르다.

| 소재 | 근거 | 이행강제금 |
|---|---|---|
| **읍·면** | 농어촌빈집특별법 §45 | 500만원 이하 **정액** |
| **동** | 빈집특례법 §65 | 1㎡당 시가표준액 **50% × 연면적** 이하 |

**즉 진단서 문구가 주소에 따라 갈려야 한다.** 4축 설계에는 이 분기가 없다.
포항 남·북구 안에도 동이 있으므로 "시골이니까 읍·면"으로 뭉갤 수 없다.

`laws.json`의 `/위계/해소됨/새발견`에 더 까다로운 구간이 적혀 있다 —
**2027-06-17부터 준농어촌 빈집이 빈집특례법으로 편입**되므로
읍·면/동 이분법만으로 판별하면 이 구간을 놓친다.

반영할 곳 — 설계서에 분기 조건으로 추가하고,
계획서 Task 6(`관리 부담` 항목)·Task 7(`manage` 경로)에 주소 기반 분기를 넣는다.

### 용어 하나 더

`laws.json` 농어촌빈집특별법 §2제2호 메모 —
**법적 '빈집'은 지자체 확인이 있어야 성립한다.** 신청자가 비어 있다고 해도
아직 법적 빈집이 아니므로 **진단서 본문은 '이 주택'으로 쓴다.**
문서·코드에서 소유주에게 나가는 문장에 '빈집'을 쓰지 않았는지 함께 확인할 것.

### 진실의 출처

`src/rules/laws.json` — 법명을 코드에 문자열로 박지 않고 여기 모아둔 대장이다.
원문 대조가 끝난 상태이므로 **문구를 새로 쓸 때 이 파일을 근거로 삼는다.**

## 9. 🏗 건축법 — 나중에 볼 것 (2026-09-06 기록)

> **상태: 미착수.** 세법(§1·§2)을 먼저 보고 나중에 다룬다.
> 내용은 단단하다고 보지만 **조문 번호는 전부 미확인**이다.

### 왜 봐야 하나

용도변경·대수선 규제가 ③건물·토지축과 `정비`·`임대` 경로에 걸린다.
**결론부터: 우리 타깃에게는 대부분 유리하게 작동한다** — 면적이 작아서다.

### 세 갈래

**① 대수선 — 우리 타깃은 「신고」로 끝난다**

대수선은 원래 허가 대상이다. 내력벽 30㎡ 이상 수선, 기둥·보·지붕틀 3개 이상
손대면 걸리므로 시골집 리모델링은 거의 다 여기 들어간다.

**그런데 연면적 200㎡ 미만 + 3층 미만이면 신고로 갈음된다.**
예시 필지가 66㎡·1층이니 통과한다. 허가와 신고는 비용·기간이 확실히 다르다.

**② 용도변경 — 여기가 진짜 벽이다**

9개 시설군 체계이고 **상위군으로 올라가면 허가**다.

```
단독주택 (주거업무시설군)  →  카페·음식점 (근린생활시설군)
                              상위군 = 허가
```

농어촌 빈집 활용에서 제일 자주 막히는 지점이다.

**단, 농어촌민박은 예외다.** 「농어촌정비법」상 농어촌민박은
단독주택 연면적 **230㎡ 미만**이면 **용도변경 없이** 가능하다.
우리 타깃에 정확히 맞고, 활용 경로에서 가장 현실적인 답이다.

**③ 딸려오는 것들 — 이쪽이 실제 병목**

용도변경 자체보다 부수 요건에서 막힌다.

| | 왜 막히나 |
|---|---|
| **주차장** | 근생으로 바꾸면 주차 대수 요건 발생. **시골 좁은 필지에서 제일 자주 걸린다** |
| 정화조 용량 | 하수도법. 용도 바뀌면 재산정 |
| 소방시설 | 용도변경 시 추가 |
| 접도 2m | 건축법. **우리 룰에 이미 맹지 판정이 있다** (`P-MAENGJI`) |

### MVP에 넣을 만한 건 3개다 — 이미 가진 데이터로 판정된다

폼에 *"뭘 하고 싶으신가요"*가 없으니 규제 전체를 다루면 답이 안 나온다.
대신 **면적 하나로 갈리는 것**만 경로에 한 줄씩 붙인다.

```
buildingArea < 200㎡   →  정비 경로:  "대수선은 허가가 아니라 신고로 됩니다"
buildingArea < 230㎡   →  임대 경로:  "농어촌민박은 용도변경 없이 가능합니다"
landArea + roadSide    →  임대 경로:  "카페·음식점은 주차장이 실제 관문입니다"
```

`buildingArea`·`landArea`·`roadSide` **전부 이미 파이프라인에 있다.**
새 API도, 새 폼 문항도 필요 없다.

성격이 ②세금축과 같다 — **"생각보다 괜찮다"로 안심시키는 축.**
소유주는 "리모델링하려면 허가 받아야 한다던데"를 막연히 알고 있는데
실제로는 신고면 된다.

### 확인할 것 (조문 번호는 전부 미확인)

**내용은 위 그대로가 맞다고 본다.** 200㎡/3층, 230㎡, 9개 시설군,
상위군=허가 — 이건 단단하다. 반면 **조문 번호와 시설군 순번**은
§8의 사고를 겪은 만큼 원문 대조가 필요하다.

- [ ] **대수선 신고 갈음 요건** — 200㎡ 미만 + 3층 미만이 맞는가 (건축법 §14 추정)
- [ ] **대수선의 정의** — 내력벽 30㎡, 기둥·보·지붕틀 3개 이상 (건축법 §2①9호 추정)
- [ ] **농어촌민박 용도변경 면제** — 230㎡ 미만이 맞는가 / 신고·지정 절차는 무엇인가
      (농어촌정비법 §86 추정)
- [ ] **단독주택 → 제1종근생이 허가인가 신고인가** — 시설군 순번 확인
      (건축법 §19②·④ 및 시행령 §14⑤ 추정). 번호가 작을수록 상위군이 맞는가
- [ ] 주차장 대수 요건 — 근생 용도별 산정 기준 (주차장법 시행령)
- [ ] 포항시 주차장 조례에 농어촌 완화 규정이 있는가

확인되면 `laws.json`의 `laws.건축법`·`laws.농어촌정비법` 항목에 조문을 채우고,
설계서 §6(경로)과 계획서 Task 7에 위 3줄을 넣는다.

## 10.2 ⚠️ 농어촌주택 특례 — 제 설계가 방향을 거꾸로 잡았다

조특법 §99의4 제1항 구조:

> 1세대가 2003-08-01부터 [종료일]까지 **농어촌주택을 취득**하여 **3년 이상 보유**하고,
> 그 **농어촌주택 취득 「전에」 보유하던 다른 주택(일반주택)을 양도**하는 경우
> → 농어촌주택을 소유주택이 아닌 것으로 본다

**이 특례는 시골집을 팔 때가 아니라 「도시 아파트를 팔 때」 쓰는 것이다.**
설계서 §4.3과 계획서 Task 6의 `disposalLines`는 이걸 "시골집 처분 시 볼 것"으로
써놨는데 틀렸다.

### 그런데 우리 타깃에 오히려 유리하다

| 확인된 것 | 내용 |
|---|---|
| **상속도 '취득'에 포함** | *"취득이란 매매로 인한 취득뿐만 아니라 **증여, 상속**, 직접 건설하여 취득한 것을 포함"* |
| **순서 요건이 결정적** | 일반주택 먼저 → 농어촌주택 나중. **반대면 적용 불가** |
| 면적 요건 | 2021-01-01 이후 양도분부터 **삭제** |
| 지역 요건 | 읍·면 소재. 제외 — 수도권(연천·옹진 제외) · **도시지역** · 조정대상지역 · 토지거래허가구역 · 관광단지 |

우리 타깃의 전형 케이스가 **순서 요건을 자연스럽게 충족한다.**

```
① 도시에 아파트 구입      (먼저)
② 부모님 사망 → 시골집 상속 (나중)
→ 순서 충족 → 아파트 양도 시 시골집을 주택 수에서 제외
```

즉 진단서가 할 말이 이렇게 바뀐다 —
*"시골집 때문에 2주택이 돼 도시 아파트 팔 때 세금이 걱정되신다면,
농어촌주택 특례로 시골집을 주택 수에서 빼는 길이 있습니다."*

**「보유해도 괜찮다」를 뒷받침하는 두 번째 근거다.** 재산세 다음으로 세다.

### 남은 것

- [ ] **기준시가 상한** — 자료가 갈린다: 2억 / 3억(한옥 4억). 개정 이력 확인 필요.
      **우리 타깃(공시 6,080만원)은 어느 쪽이든 통과**하므로 급하지 않다.
- [ ] **취득기간 종료일** — 자료가 갈린다: 2022-12-31 / 2025-12-31 / 2028-12-31.
      **상속 시점이 이 기간 안이어야 하므로 반드시 확정해야 한다.**
- [ ] **포항 읍·면 해당 여부** — 포항 인구 약 49만으로 20만을 넘으므로
      **동 지역은 대상이 아니고 읍·면만** 해당할 것으로 보인다. 확인 필요.
- [ ] 조문 제목이 「인구감소지역 및 기회발전특구 주택」으로 표기된 자료가 있다.
      조문 재편 여부 확인.

## 10.4 ⚠️ 농어촌민박 — 거주 요건을 빼먹었다

조문 위치는 **「농어촌정비법 시행규칙」 별표 3 제1호**다 (§86 추정은 부정확했다).

> 농어촌지역 또는 준농어촌지역 **주민이 거주하고 있는** 연면적 230㎡ 미만의 단독주택

**「거주하고 있는」이 요건이다.** §9에 쓴
*"농어촌민박은 용도변경 없이 가능합니다"*는 이걸 빠뜨려 오해를 준다.
**비어 있는 상속 시골집은 그대로 민박이 안 된다.** 소유주가 그 집에 거주해야 한다.

정확한 문구는 이렇게 되어야 한다 —
*"소유주께서 이 집에 거주하시게 되면, 연면적 230㎡ 미만이라
용도변경 없이 농어촌민박을 신고하실 수 있습니다."*

즉 `임대` 경로가 아니라 **`보유·세컨드하우스`·귀농 경로와 묶여야** 성립한다.
설계의 경로 배치가 바뀐다.

- 부속건축물 포함 **전체 연면적 합계**가 230㎡ 미만이어야 한다
- 동일 지번의 여러 동은 하나의 민박으로 신고 가능
- 주용도가 주택이고 타용도 면적이 주택보다 작아야 한다

## 10.5 🔑 파생 필드 하나가 반드시 필요하다

**「읍·면/동」과 「도시/비도시」 판별이 세 곳에서 쓰인다.**

| 쓰이는 곳 | 판별 |
|---|---|
| 빈집법 관할 (§8) | 읍·면 → 농어촌빈집특별법 / 동 → 빈집특례법 |
| 농어촌주택 특례 (§10.2) | 읍·면 **그리고** 비도시지역이어야 대상 |
| 재산세 도시지역분 (§10.1) | 도시지역 **그리고** 고시 지역이어야 부과 |

지금은 어디에도 이 판별이 없다. `facts`에 두 필드를 만들어야 한다.

```
areaType   : '읍' | '면' | '동'        ← resolvedAddress 에서 파싱
urbanZone  : boolean                   ← zone1 이 도시지역 4종에 걸리는지
```

`resolvedAddress`와 `zone1`이 **이미 파이프라인에 있으므로** 새 API는 필요 없다.
설계서에 파생 필드로 추가하고, 계획서 Task 3(facts 병합)에 넣는다.
